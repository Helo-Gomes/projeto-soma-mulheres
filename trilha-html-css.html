Como funciona

Cada recurso abaixo é de outro criador ou plataforma. O SOMA+ organiza a ordem; o conteúdo é mantido por quem o produziu.

Ver recursos

Isso é uma curadoria, não um curso próprio. Selecionamos o que há de melhor sobre HTML e CSS na internet e organizamos numa ordem que faz sentido para quem está começando. A maior parte é 100% gratuita; a Codecademy é uma plataforma paga, mas com bastante conteúdo liberado sem custo. Os links abrem direto no canal, site ou material do criador original.
